# Как выложить сайт в интернет (бесплатно)

После этих шагов сайт будет работать по постоянной ссылке для всех, а заявки — приходить
в Telegram круглосуточно (даже когда ваш компьютер выключен).

Всё бесплатно. Используются три сервиса:

| Сервис | Зачем |
|---|---|
| **GitHub** | хранит файлы сайта |
| **Neon** | база данных (цены, работы, заявки) |
| **Render** | запускает сайт и сервер |

> ⚠️ Файл `server/.env` **не загружайте** — в нём пароли. Его содержимое мы впишем в Render вручную.

---

## Шаг 1. GitHub — загрузить файлы

1. Заведите аккаунт на [github.com](https://github.com) (если ещё нет).
2. Нажмите **New repository**. Имя — например `nail-studio`. Тип — **Public**. Создайте.
3. На странице репозитория нажмите **Add file → Upload files**.
4. Перетащите туда **всё содержимое папки сайта**, кроме:
   - папки `server/node_modules` (её нет),
   - файла `server/.env` (секреты — не грузим).
5. Нажмите **Commit changes**.

---

## Шаг 2. Neon — база данных

1. Зайдите на [neon.tech](https://neon.tech) и создайте аккаунт.
2. Создайте проект (Project), регион ближе к вам (например, Frankfurt).
3. Найдите **Connection string** (строка вида
   `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`).
   Скопируйте её — пригодится в шаге 3.

---

## Шаг 3. Render — запуск сайта

1. Зайдите на [render.com](https://render.com) и войдите через **GitHub**.
2. Нажмите **New → Blueprint**, выберите ваш репозиторий `nail-studio`.
   Render сам прочитает файл `render.yaml` и предложит создать сайт `nail-studio`.
3. Введите значения переменных (Render спросит):
   - **ADMIN_PASSWORD** — пароль для входа мастера (придумайте надёжный);
   - **DATABASE_URL** — строку из шага 2;
   - **TELEGRAM_BOT_TOKEN** — токен бота;
   - **TELEGRAM_CHAT_ID** — id чата мастера.
4. Нажмите **Apply / Create**. Подождите 2–5 минут, пока идёт сборка.
5. Готово! Render выдаст адрес вида `https://nail-studio-xxxx.onrender.com`
   — это и сайт, и панель мастера (`/admin.html`).

---

## Шаг 4. Первый вход и проверка

1. Откройте `https://ваш-адрес.onrender.com/admin.html`.
2. Войдите: логин **admin**, пароль — тот, что задали в шаге 3.
3. Вкладка **«Уведомления»** → кнопка **«Отправить тест»** — бот должен написать вам.
4. Откройте сайт (`https://ваш-адрес.onrender.com`), отправьте тестовую заявку —
   она придёт в Telegram, а на странице появится «Заявка отправлена ✓».
5. Сразу смените пароль: вкладка **«Публикация» → «Смена пароля»**.

---

## Чтобы сайт не «засыпал» (по желанию, но советую)

Бесплатный Render останавливает сайт после 15 минут без посетителей, и первый заход
может подождать ~минуту. Чтобы этого не было:

1. Заведите бесплатный аккаунт на [uptimerobot.com](https://uptimerobot.com).
2. Добавьте монитор типа **HTTP(s)**, адрес — `https://ваш-адрес.onrender.com/api/data`,
   интервал — **5 минут**.

Так сайт всегда «бодрый». Лимита бесплатных часов Render (750 в месяц) хватает ровно на один сайт круглосуточно.

---

## Свой красивый адрес (по желанию)

Если купите домен (например, `valinnails.ru`), в Render: **Settings → Custom Domain** →
добавьте домен и пропишите указанные там DNS-записи у регистратора.

---

## Если что-то пошло не так

- **Сайт не открывается** — подождите 1–2 минуты после первого захода (Render запускается).
- **Ошибка входа** — проверьте `ADMIN_PASSWORD` и `ADMIN_USER` в Render → Environment.
- **Не приходят уведомления** — проверьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`,
  нажмите «Отправить тест» в панели.
- **Данные сбросились после деплоя** — так бывает, если не задан `DATABASE_URL`.
  Проверьте переменную и **Redeploy**.
