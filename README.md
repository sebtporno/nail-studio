# Сайт студии маникюра

Нежно-розовый сайт-визитка: главный экран, «Обо мне», услуги и цены, портфолио работ, новости, контакты и форма записи.

## Как всё устроено

- **`index.html`** — сам сайт. Открывается двойным кликом, работает без интернета (кроме шрифтов).
- **`admin.html`** — панель мастера. Здесь мама добавляет работы, меняет цены, пишет новости и правит контакты.
- **`data/data.js`** — файл данных. Правится только через панель, вручную трогать не нужно.
- Все изменения в панели автоматически сохраняются на этом компьютере в браузере.
- Для публикации изменений в интернете необходимо скачать файл данных из панели и заменить его в папке сайта (шаги ниже).

> Сайт умеет работать **двумя способами** — выберите один:
> 1. **Простой** (эта инструкция): без сервера, всё хранится в браузере, обновление через файл `data.js`. Подходит, если сайт просто визитка.
> 2. **Сервером** (папка `server/`): панель мастера открывается **онлайн**, мама входит по логину и паролю и добавляет работы с телефона — сайт обновляется сразу, перезаливать ничего не нужно. Требует сервер и базу PostgreSQL (есть бесплатные варианты). Смотрите раздел «Вариант с сервером» ниже.

## Как маме добавить новую работу (пошагово)

1. Откройте файл **`admin.html`** двойным кликом.
2. Вкладка **«Мои работы»** → кнопка **«Добавить работу»**.
3. Нажмите **«📷 Фото работы»** и выберите фото с телефона или компьютера
   (фото автоматически сожмётся, размер не важен — подойдут фото до ~10 МБ).
4. Впишите название работы и категорию, например «Маникюр» или «Наращивание».
5. Всё сохранится автоматически. Готово — можно закрывать панель.

Точно так же добавляются **новости** (вкладка «Новости») и меняются **цены** (вкладка «Услуги и цены»).

## Как выложить сайт в интернет (бесплатно)

### Первый раз — Netlify

1. Зарегистрируйтесь на [netlify.com](https://www.netlify.com) (бесплатно).
2. Перетащите **всю папку сайта** (папку, где лежат `index.html`, `assets` и т.д.)
   в окно браузера на странице вашего аккаунта.
3. Netlify сам создаст адрес вида `имя-сайта.netlify.app` — скиньте его клиентам.

### Как обновить сайт после изменений

1. В панели `admin.html` откройте вкладку **«Публикация»**.
2. Нажмите **«Скачать файл данных (data.js)»**.
3. Удалите старый `data.js` в папке `data` сайта и положите на его место скачанный.
4. Зайдите на Netlify → ваш сайт → вкладка **Deploys** → перетащите **всю папку сайта**
   в зону загрузки прямо в браузере. Готово, изменения на сайте через пару минут.

> Важно: всегда перетаскивайте **всю папку целиком**, а не один файл.
> Адрес сайта при таком способе не меняется.

## Резервная копия и перенос на другой компьютер

- **Резервная копия** — это скачанный из панели файл `data.js`. Храните его в надёжном месте.
- **Перенос:** на другом компьютере положите скачанный `data.js` в папку `data`,
  затем откройте `admin.html` → вкладка «Публикация» → **«Импортировать данные из файла»** и выберите его.
  Работы и тексты появятся так же, как были.

## Если что-то перепутали

В панели на вкладке «Публикация» есть кнопка **«Сбросить все данные»** —
она вернёт сайт к стандартным данным (сгенерированным примерам) и удалит добавленные фото. Пользуйтесь осторожно.

## Вариант с сервером (панель онлайн)

Нужен, если хотите, чтобы мама **сама** добавляла работы и новости прямо с телефона, а сайт обновлялся мгновенно — без скачивания `data.js` и перезаливки.

Технологии: **Node.js + Express + PostgreSQL**. Всё уже написано в папке `server/`.

### Как запустить на своём компьютере (проверить)

**Самый простой способ:** двойной клик по файлу **`start.bat`** в папке сайта.
Первый запуск занимает 1–2 минуты (подгружаются компоненты), дальше — мгновенно. Браузер откроется сам.
Пока вы пользуетесь сайтом, чёрное окно закрывать нельзя — это и есть сервер.

Если предпочитаете вручную:

1. Установите [Node.js](https://nodejs.org) (кнопка LTS).
2. Откройте терминал в папке `server` и выполните:
   ```bash
   npm install
   npm start
   ```
3. Откройте в браузере `http://localhost:3000` — это сайт, а `http://localhost:3000/admin.html` — панель мастера.
4. Вход по умолчанию: логин **admin**, пароль **admin123** (смените его в панели на вкладке «Публикация»).

> **Важно:** форму записи нужно открывать по адресу `http://localhost:3000` (через сервер), а не двойным кликом по `index.html`.
> Если открыть файл напрямую, сервера рядом нет — форма не сможет отправить заявку, и уведомление в Telegram не придёт.

> Локально отдельный PostgreSQL ставить не обязательно — при первом запуске поднимается встроенная база.
> Для реального сайта нужен настоящий PostgreSQL (см. ниже).

### Настройки (файл `server/.env`)

Скопируйте `server/.env.example` в `server/.env` и задайте:

```
PORT=3000
JWT_SECRET=длинная-случайная-строка
ADMIN_USER=admin
ADMIN_PASSWORD=надёжный-пароль
DATABASE_URL=postgres://пользователь:пароль@хост:5432/база
TELEGRAM_BOT_TOKEN=токен-от-BotFather
TELEGRAM_CHAT_ID=ваш-id-в-telegram
```

### Как выложить в интернет (бесплатно)

1. Создайте бесплатную базу PostgreSQL, например на [Neon](https://neon.tech) или [Supabase](https://supabase.com).
   Скопируйте строку подключения в `DATABASE_URL`.
2. Залейте проект на [Render](https://render.com) или [Railway](https://railway.app):
   - корень проекта — папка `server`;
   - команда запуска: `npm start`;
   - добавьте переменные окружения из `.env` (обязательно новые `JWT_SECRET` и `ADMIN_PASSWORD`).
3. После деплоя получите адрес вида `https://ваш-сайт.onrender.com` — это и сайт, и панель (`/admin.html`).

> Бесплатные тарифы Render «засыпают» при простое — первый заход может занять несколько секунд. Для визитки этого достаточно.

### Что умеет сервер

- Вход мастера по логину и паролю (пароль хранится в зашифрованном виде).
- Профиль, цены, работы, новости — всё сохраняется в базе и сразу видно на сайте.
- Загрузка фото работ (JPG/PNG/WEBP до 12 МБ; фото сжимается в браузере перед отправкой).
- **Заявки с сайта** — все заявки из формы складываются в панели на вкладке «Заявки», а клиент видит подтверждение «Заявка отправлена».
- **Уведомления в Telegram** — при новой заявке мастеру сразу приходит сообщение в Telegram (со звуком и пуш-уведомлением на телефон). Настраивается кнопкой в панели, вкладка **«Уведомления»**.

### Как включить уведомления в Telegram (2 минуты)

1. Откройте Telegram, найдите бота **@BotFather** и отправьте ему команду `/newbot`. Ответьте на вопросы — в конце BotFather пришлёт **токен** (длинная строка из цифр и букв).
2. Откройте своего нового бота (ссылка вида `t.me/имя_бота`), нажмите **Start** и отправьте ему любое сообщение (например, «привет»).
3. В панели мастера (`/admin.html`) откройте вкладку **«Уведомления»**, вставьте токен и нажмите **«Подключить»**. Затем — **«Отправить тест»**: в Telegram придёт проверочное сообщение.
4. Готово. Теперь каждая заявка с сайта будет приходить вам сообщением в Telegram.

> Настройки можно задать и заранее — переменными `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `server/.env` (тогда панель ничего вводить не потребует).

### Тесты

```bash
cd server
npm test
```

Проверяют вход, сохранение данных, загрузку фото, заявки, безопасность и Telegram-уведомления (20 проверок).

## Технические детали (для разработчика)

- **Без сервера:** чистые HTML/CSS/JS без сборки — работает через `file://` и на любом статическом хостинге.
  Тексты/настройки: `localStorage`, фотографии: IndexedDB (сжатие до ~1400px JPEG).
  Ссылки на картинки вида `idb:<key>`; экспорт превращает их в `data:`-URL (самодостаточный файл).
- **С сервером:** фронтенд сам определяет, есть ли рядом API (`/api/health`).
  Если есть — берёт данные из `/api/data`, а админка работает онлайн; если нет (открыто как файл) — работает как раньше.
  Таблицы: `admin_users`, `settings` (JSON-профиль), `prices`, `works`, `news`, `bookings`. Схема — `server/src/schema.sql`.
  Загруженные фото лежат в `server/uploads/` и отдаются по `/uploads/...` (папка не коммитится).
- Резервные логотипы — заглушки в `assets/img/` (заменяются реальными фото из панели).
